# Thermopair UI/UX Lab

This is an experimental copy of the Thermopair website.

The original Thermopair project is the source of truth and must not be modified as part of experiments performed here.

## Purpose

This project exists to:

- Test UI/UX skills and tools
- Test UI UX Pro Max
- Explore alternative design systems
- Improve visual hierarchy
- Test typography, spacing and color systems
- Experiment with navigation and CTAs
- Test new page layouts
- Test new components
- Explore stronger product and technical presentation
- Improve responsive behavior
- Improve accessibility
- Compare experimental designs against the currently approved Thermopair website

## Important Rules

- Changes made here should NOT automatically be applied to the original Thermopair project.
- The original project remains the approved baseline.
- Experiments may be aggressive and exploratory.
- Preserve the business content unless an experiment specifically requires changing it.
- Any successful experiment should be reviewed before being manually ported back to the original project.

## Design Context

Thermopair is a B2B industrial company.

The website should communicate:

- Engineering expertise
- Reliability
- Precision
- Manufacturing capability
- Technical credibility
- Quality
- Professionalism

Primary audiences include:

- Engineers
- Procurement teams
- Industrial buyers
- Technical decision makers

Primary conversion goals:

- Request a Quote
- Contact Thermopair

The website should feel:

- Industrial
- Technical
- Precise
- Trustworthy
- Modern
- Premium
- Established

It should NOT feel like:

- A generic SaaS startup
- An AI startup
- A consumer e-commerce website
- A trendy template
- A crypto/Web3 website

Avoid unnecessary:
- excessive gradients
- glassmorphism
- decorative animations
- futuristic AI aesthetics
- generic startup illustrations
